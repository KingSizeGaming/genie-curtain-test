# Genie curtain phone test

Compiled animation bench for device testing. Open https://kingsizegaming.github.io/genie-curtain-test/ on a phone.

Press PLAY, then test SKIP, STOP, RESET, MOTION OFF, SPEED 2x, and LOOP. The covered cue switches the background while the curtain is closed. The log shows frame timings.

This repository contains the compiled test build and artwork only. No math, server, or wagering functionality is included.
