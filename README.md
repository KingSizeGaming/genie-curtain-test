# Genie animation phone tests

Open https://kingsizegaming.github.io/genie-curtain-test/ on your phone.

Scene preview: https://kingsizegaming.github.io/genie-curtain-test/scene/

The scene is a fixed, labelled animation sample with jackpot board, updated genie, two chests, bank/multiplier and 5 x 3 reels. PLAY runs its 23-second storyboard. The bench selector retains earlier animations and adds 27 native coin, banner and genie clips, including separate completion-banner stages and blank variants. Everything supports Play, Skip, Stop, Reset, Motion Off and 2x speed. No math, random outcomes, buys, ante or event contract are implemented.

For device measurements, open Scene, press 30s TEST, then SAVE REPORT. Record the actual phone model and browser alongside the JSON; use a cold load for download measurements. Browser viewport results do not prove physical-phone performance. A physical mid-range phone report is still pending.

The bench opens on Genie: lamp and smoke entrance, layered character reveal, floating idle, presenting gesture, sample award count and smoke exit. Chests, Symbols, Lamp & Award, Big Win, Huge Win, Mega Win, and Curtain remain in the selector.

Press PLAY or enable LOOP. Controls also include SKIP, STOP, RESET, MOTION OFF, and SPEED 2x. These are presentation previews, not game outcomes; no payout, threshold, or random result is calculated. Source coin numerals are supplied sample artwork.

This public repository contains compiled test assets and artwork only. SDK source and game math remain private. Earlier hashed bundles remain for cache compatibility.
